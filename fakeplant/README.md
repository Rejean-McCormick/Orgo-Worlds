# Projection FakePlant pour Orgo_Worlds

`world-packs/fakeplant/` est le pack de scénarios. `fakeplant/fixture/` est une projection intacte du Kristal v1.1, utilisée uniquement pour qualification et projection d'identités dans l'application Orgo. Aucun mot de passe utilisable et aucune donnée réelle.

La mise à jour de l'application Orgo récupère ce répertoire depuis le dépôt voisin; on ne duplique pas son contenu dans le dépôt principal. Les packs ne modifient aucune base à l'extraction.
