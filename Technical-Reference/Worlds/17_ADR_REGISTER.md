# ADR register

- **ADR-W01** — Orgo Worlds est un dépôt/deploiement standalone, pas un module du repo Orgo.
- **ADR-W02** — Isolation World par clés de lignes, pas `search_path` dynamique.
- **ADR-W03** — WorldRelease est une génération de configuration/provenance, pas une copie de l'historique opérationnel.
- **ADR-W04** — Route runtime canonique `/api/v3/w/{key}` avec réécriture interne.
- **ADR-W05** — Identité organisationnelle; membership World additive.
- **ADR-W06** — Worker context pinned à la release de l'Outbox.
