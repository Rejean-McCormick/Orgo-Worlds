# Glossaire

- **World** : espace opérationnel logique d'une organisation.
- **WorldRelease** : génération de configuration/provenance d'un World.
- **Current release** : release utilisée pour les nouvelles écritures.
- **Pinned release** : release inscrite sur une donnée ou un message au moment de sa création.
- **WorldMembership** : rôle local au World (`owner`, `maintainer`, `member`, `viewer`).
- **Control plane** : API qui crée/archive les Worlds et gère releases/membres.
- **Runtime plane** : API métier scindée par `world_id`.
- **Main** : World par défaut de compatibilité.
